问题

windows 操作系统启动 wsl 后会导致部分较小的端口被占用，例如 ss 常用的端口 1080。

通常情况，如果通过命令 netstat -ano|findstr "1080" 无法查找的端口号是被进程占用的那很可能就是被 windows 保留端口占用了。
